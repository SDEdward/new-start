## Code Formatting & Style

Please follow these conventions to keep things clean and consistent:

- ~~Use [**Prettier**](https://prettier.io/) for formatting.~~ nvm use rust-analyser cuz prettier dosent support rust
- Use **`snake_case`** for most variable and file names. (i like it the most)
- Prefix **code folders** with an underscore (`_`) so they appear first in file explorer.
- Add your files and folders to `.gitignore` if they shouldn't be tracked. (make exception for the /src/)
- Place the **compiled build of your program** in the `release/` folder at the root of the project if u want.
- If you're familiar with GitHub Actions, feel free to add your program to the workflow. If you dont know how i dont know either
