# 🛠️ Installation Guide

There are two ways to install and run this program:

## 1. Local Installation

This method allows you to run the program only from the directory where it's located.

### Linux

```bash
./<program_name>
```

### Windows

```cmd
.\<program_name>
```

---

## 2. Global Installation

This method lets you run the program from anywhere on your system—just like any other system-wide command.

### Linux

Move the program to a directory that's part of your system's `PATH`, such as `/usr/bin`:

```bash
sudo mv <current_location_of_program> /usr/bin/
```

Then you can run it from anywhere:

```bash
<program_name>
```

### Windows

To make the program globally accessible:

1. Move `<program_name>.exe` to a directory included in your system's `PATH`. I reccomand:

   - `C:\Windows\System32`
   - Or create a custom folder like `C:\Programs\MyTools` and add it to your `PATH`. (NOT RECOMMENDED FOR UNEXPERIENCED USERS!)

2. Now you can run the program from any command prompt:

```cmd
<program_name>
```
